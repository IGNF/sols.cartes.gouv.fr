# M16 : vignettes des fonds de cartes, zoom sous le plein écran

## Vignettes vides de l'onglet « Fonds de cartes »

- Cause : les entrées des fonds n'ont pas de `thumbnail` ; avec `layerThumbnail: true`, geopf met `"default"` et peint une
  vignette d'attente vide (`.catalog-thumbnail-default`, image SVG en fond, `DSFRcatalogStyle.css`).
- Source : configuration de cartes.gouv.fr (`IGNF/cartes.gouv.fr-entree-carto`, `public/data/entreeCarto.json`, champ
  `thumbnail` par couche) : `https://data.geopf.fr/annexes/ressources/metadata/thumbnail/vignette-<nom>.jpg`, chaque fichier
  vérifié en `curl` (200 `image/jpeg`).
- `gpfThumbnailUrl(file)` (`src/config/urls.ts`), `thumbnail` dans `BASE_LAYER_CANDIDATES` (`src/config/map.ts`), porté par
  `availableBaseLayers` puis `buildCatalogData` (hôte de confiance seulement).
- Pas d'image plutôt qu'une vignette vide ou cassée : `.catalog-thumbnail-container:not(:has(img))` masqué (`MapView.css`) ;
  `dropBrokenThumbnails` (`src/map/catalogThumbnails.ts`) retire une image en erreur (évènement `error` capturé).
- Vérifier aussi les vignettes CSW de « Données sols » et l'aperçu carte du catalogue geonetwork (fond de carte, sans modifier la
  brique ; `M-n` dans `QUESTIONS.md` seulement si une correction de configuration existe).

## Zoom en bas à droite, sous le plein écran

- `MAP_TOOLS_OPTIONS.zoom.position: 'bottom-right'`, comme cartes.gouv.fr (`zoomOptions`/`fullscreenOptions`). Le plein écran
  est ajouté avant le zoom, qui s'ajoute à la suite dans le même conteneur : plein écran au-dessus, zoom dessous ; échelle à gauche.
- Ordre du clavier : `GeoportalZoom` et `GeoportalFullScreen` créent chacun leur conteneur de position ; créé en premier, celui du
  bas à droite passerait avant tous les autres. `ensurePositionContainers` crée les quatre conteneurs dans l'ordre de lecture.
