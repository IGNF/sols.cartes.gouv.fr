# M3: outils de carte et catalogue de fonds

## Objectif
Carte complète : zoom, échelle, attributions, plein écran, recherche (géocodage GPF) et géolocalisation ; catalogue de fonds
raster prédéfinis, filtré contre le GetCapabilities WMTS à l'exécution ; panneau DSFR « Fonds de carte » (boutons radio).

## Choix (API vérifiée dans les `.d.ts` / sources geopf-ext 1.0.0-beta.16)
- geopf-ext : `GeoportalZoom`, `GeoportalAttribution`, `GeoportalFullScreen`, `SearchEngine` (`displayButtonGeolocate`,
  autocomplétion `data.geopf.fr/geocodage/completion`, géocodage `/geocodage/search`, sans `Gp.Config` car `resources.search` reste à `false`).
- OpenLayers : `ScaleLine` (geopf-ext n'en fournit pas), `Rotate` (libellé français).
- Fonds candidats dans `src/config/map.ts` ; `availableBaseLayers()` ne garde que ceux publiés ; titre lu dans les capacités.
- État : `activeBaseLayerId` et `isPanelOpen` dans le store ; le fond effectif est dérivé (repli sur le premier disponible).
- M-2 : nouvel essai unique d'une tuile en erreur après un court délai (`tileloaderror`), seulement si l'erreur se reproduit.
