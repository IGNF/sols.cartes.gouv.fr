## Étapes
1. Relever la prod `cartes.gouv.fr/rechercher-une-donnee` (index, `default.toml`, bundle `main.*.js`) et identifier la ref du fork servie.
2. Comparer les refs du fork (`main`, `datahub-ign-*`, tags `v1.6.x`, releases, `wc-dist-*`), choisir une ref épinglée.
3. Lire le code à la ref épinglée : route `search`, synchro URL -> état NgRx, champ `organization`, construction de la requête ES, options de `[search]`, bouton visualiseur externe.
4. Interroger l'API GeoNetwork (`_search`, `site`, `sources`, `groups`) et le CSW `gissol-osf_c` ; comparer les identifiants.
5. Cloner (shallow) la ref, `npm ci`, construire `datahub` avec `--base-href=/rechercher-une-donnee/` ; mesurer temps, disque, mémoire ; servir le build et vérifier le filtre organisation avec Playwright.
6. Rédiger la recommandation pour C2/C3/C4 (mécanisme « sols seulement », mode de construction, versions node/npm).
