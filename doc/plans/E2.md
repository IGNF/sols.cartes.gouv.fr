# E2 : page d'accueil et pages de pied de page (brique edito)

## Objectif

Accueil conforme à l'ordre des sections de la maquette Figma (frame « 1440w light », nœud 8:4414) avec des
composants DSFR, et quatre pages provisoires liées depuis le pied de page. Appliquer les remarques de revue d'E1.

## Fichiers

- `src/_data/site.js` : titre de service « sols.cartes.gouv.fr », devise « Observatoire des sols de France »,
  description unique, clé `infoGouv`, liens de pied de page alignés sur l'exemple DSFR 1.14.2.
- `src/_data/accueil.js` : contenu de l'accueil (textes provisoires, pictogrammes).
- `src/index.njk` : héros (surtitre, h1, introduction, deux boutons), « Le service » (3 tuiles), « Données
  disponibles » (3 cartes vers le catalogue), encadré GIS Sol (`fr-callout`).
- `src/_includes/layouts/page.njk` + `partials/breadcrumb.njk` ; `src/pages/*.njk` : accessibilité, mentions
  légales, données personnelles, plan du site (liste des sections).
- `src/css/site.css` : fond du héros et surtitre (jetons DSFR uniquement).
- `eleventy.config.js` : copie des pictogrammes DSFR utilisés et de `css/`.
- `partials/header.njk`, `partials/footer.njk` : `rel="noopener external"`, retrait de `aria-haspopup`.
- `doc/agents/edito.md` : balisage rendu identique octet pour octet à `dist/index.html` ; Q7 dans QUESTIONS.

## Tests

- Fumée : sections de l'accueil, liens catalogue / carto / GIS Sol, quatre pages avec h1, title, description.
- Synchronisation : chaque bloc HTML de `doc/agents/edito.md` est une sous-chaîne de `dist/index.html`.
- `bun run lint`, `bun run test`, `bun run build` ; `build:all` + `preview:all`, curl et captures Playwright.
