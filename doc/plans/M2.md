# M2: cœur cartographique (OpenLayers + geopf-extensions-openlayers)

## Objectif
Carte OpenLayers dans `apps/explorer-les-cartes` : fond WMTS `GEOGRAPHICALGRIDSYSTEMS.PLANIGNV2` (data.geopf.fr),
gestionnaire de couches `LayerSwitcher` de geopf-ext, hooks `useMap` façon guichet-collaboratif, Zustand (état client)
et TanStack Query (capacités WMTS). En-tête : « sols.cartes.gouv.fr » / « Observatoire des sols de France ».

## Choix
- Couche de fond construite avec `ol/source/WMTS` + `optionsFromCapabilities` à partir du GetCapabilities WMTS GPF
  (TanStack Query, `staleTime: Infinity`), comme `useGetWMTSLayer` du guichet : le nom de couche est validé à l'exécution
  et aucune config `Gp.Config` (fichier tiers GitHub) n'est nécessaire. `LayerWMTS` de geopf-ext exige cette config.
- Imports profonds `geopf-extensions-openlayers/src/packages/...` (l'index racine tire le contrôle Panoramax et sa
  dépendance pair non installée). CSS : `ol/ol.css` + `geopf-extensions-openlayers/css/Dsfr.css` (DSFR fourni par react-dsfr).

## Fichiers
- `src/config/map.ts` (fonds, vue initiale, version WMTS), `src/config/urls.ts` (URL GetCapabilities), `src/config/site.ts`.
- `src/store/useMapStore.ts` ; `src/hooks/useWmtsCapabilities.ts`, `useMap.ts`, `useBaseLayer.ts`, `useLayerSwitcher.ts`.
- `src/map/createWmtsLayer.ts` ; `src/components/map/MapView.tsx` (+ `.css`) ; `src/main.tsx` (QueryClientProvider).
- `doc/agents/geopf-ext.md` §5.

## Tests
Vitest : store, `createWmtsLayer` (extrait réel des capacités en fixture), `useWmtsCapabilities` (fetch simulé),
`useMap` / `useLayerSwitcher` / `useBaseLayer` (OL et geopf-ext simulés), `MapView` (nom accessible, états).
Navigateur : `build:all` + `preview:all`, Playwright : canvas rendu, tuiles WMTS data.geopf.fr en 200, aucune erreur console.
