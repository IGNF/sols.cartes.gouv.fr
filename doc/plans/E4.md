# E4 : référencement et indexation (brique edito)

## Objectif

`sitemap.xml` et `robots.txt` générés, URL canonique et meta description garanties sur chaque page (build en échec
sinon), vérification des liens internes de `dist/` dans `bun run test`.

## Fichiers

- `src/sitemap.njk` : `/sitemap.xml` depuis `collections.all` + racines des briques catalogue et carto ; `lastmod`
  pour les pages datées en front matter (articles).
- `src/robots.njk` : `/robots.txt`, tout autorisé, ligne `Sitemap:` avec `site.url`.
- `eleventy.config.js` : linter Eleventy qui fait échouer le build si une page HTML n'a pas de meta description non
  vide ou de canonique `site.url` + URL de la page.
- `scripts/check-links.js` (dans `apps/accueil`) : chaque `href` / `src` interne de `dist/**/*.html` doit pointer
  vers un fichier ou un dossier avec `index.html` ; ancres `#id` vérifiées dans la page cible ; racines
  `/rechercher-une-donnee/` et `/explorer-les-cartes/` admises ; liens externes ignorés. Script `check-links`.
- `test/seo.test.js` : sitemap (toutes les pages, `lastmod` des articles), robots, canonique et description sur chaque
  page, liens internes sans erreur. `test/smoke.test.js` : le plan du site lie les pages du pied de page.
- `doc/agents/edito.md` ; `doc/agents/QUESTIONS.md` : entrée E-1 (titres des cartes « Données disponibles »).

## Tests

- `bun run lint`, `bun run test`, `bun run build` ; test négatif du vérificateur de liens sur un dossier temporaire.
- `build:all` + `preview:all` : curl `/sitemap.xml`, `/robots.txt`.
