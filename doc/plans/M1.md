# M1: scaffold de la brique carto (Vite + React + TS + react-dsfr)

## Objectif
Poser `apps/explorer-les-cartes` : Vite + React 19 + TypeScript strict, `@codegouvfr/react-dsfr`,
Vitest + Testing Library (jsdom), ESLint + Prettier, base `/explorer-les-cartes/`, en-tête et pied de
page communs, page avec `<main>` et `<h1>` « Explorer les cartes ». Pas encore de carte (M2).

## Fichiers
- `apps/explorer-les-cartes/package.json` : scripts `dev` (5173), `build`, `preview`, `lint`, `typecheck`, `test`, `predev`/`prebuild` (`react-dsfr update-icons`).
- `vite.config.ts`, `vitest.config.ts` (ou bloc `test`), `tsconfig*.json` (strict, `noUncheckedIndexedAccess`), `eslint.config.js`.
- `index.html` : `lang="fr"`, `<title>`, meta description.
- `src/main.tsx` (`startReactDsfr({ defaultColorScheme: 'system' })`), `src/App.tsx`.
- `src/config/urls.ts` : chemins de rubriques, liens externes, endpoints GPF (constantes uniques).
- `src/components/layout/SiteHeader.tsx`, `SiteFooter.tsx`.
- `src/test/setup.ts`, tests `*.test.tsx`.
- `doc/agents/geopf-ext.md` : partie react-dsfr / Vite.

## Étapes
1. Installer les dépendances (react 19, react-dsfr ^1.36.0, vite, vitest, testing-library, eslint).
2. Config TS / Vite / ESLint / Vitest, scripts.
3. Constantes d'URL, Header/Footer, App.
4. Tests : le header expose les 3 liens de navigation (bonnes cibles, « Explorer les cartes » actif), App a un `main` et un `h1`.
5. Doc `geopf-ext.md`, captures dans `doc/screenshots/M1/`.

## Tests / vérifications
`bun run lint`, `bun run typecheck`, `bun run test`, `bun run build` dans l'app ; `bun run build:all` + `bun run preview:all`,
`curl` et capture Playwright de `http://localhost:8080/explorer-les-cartes/` + relevé des erreurs console.
