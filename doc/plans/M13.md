# M13 : carto v1.1

Brief : `.claude/commands/fixes.md` (section Carto). Trois PR : 1 pied de page extensible + en-tête ; 2 barre d'outils, catalogue,
outils ; 3 disposition des contrôles (échelle, plein écran, attribution).

## PR 2 : barre d'outils retirée, catalogue de cartes, outils à la demande

### Objectif
Retirer `map-explorer__toolbar` en gardant les fonctions : impression depuis la carte, fonds de carte dans le catalogue (renommé
« Catalogue de cartes », onglet « Fonds de cartes » à côté de « Données sols »), vue liste gardée mais plus liée ; partage retiré ;
barre de recherche centrée et bouton d'effacement revu ; « Mes outils » devient « Afficher tous les outils » en fin de colonne, avec
mesure de distance, de surface, dessin et itinéraire par défaut, les autres outils ajoutés à la demande (étude de
cartes.gouv.fr/explorer-les-cartes avec Playwright : liste = menu de débordement qui ouvre l'outil ; ici le bouton est ajouté).

### Choix
Voir `doc/agents/geopf-ext.md` §12.2 (catégories geopf filtrées sur `kind`, fonds = couches WMTS des capacités, contrôle OL maison pour
l'impression, `DEFAULT_TOOLS` + `revealOnOpen`).

### Fichiers
`src/components/map/{MapExplorer,MapView,PrintModal}.tsx`, `printModal.ts`, `MapExplorer.css`, `MapView.css`, `src/map/{printControl,catalogConfig,labelToolButtons}.ts`,
`src/hooks/{usePrintControl,useCatalog,useMapTools}.ts`, `src/config/map.ts`, `src/store/useMapStore.ts`, suppressions
`ShareModal`, `BaseLayerPanel`, `mapPermalink`, `scripts/check-map.ts`, `doc/screenshots/M13/`.

### Tests
Vitest (contrôle d'impression, hook, entrées fonds du catalogue, bascule du fond et recochage, outils à la demande, liste en dernier) ;
`check:map` : plus de barre d'outils, impression depuis la carte, onglet fonds, recherche centrée, outils à la demande (caché → choisi
dans la liste → bouton ajouté), mobile.

## PR 3 : disposition des contrôles

### Objectif
Retirer le bouton « Sources des données » ; échelle en bas à droite à sa place, texte et trait en `--text-action-high-blue-france` ;
plein écran en bas à droite, à droite de l'échelle (comme `cartes.gouv.fr/explorer-les-cartes/`, étudié avec Playwright : plein écran et
zoom en bas à droite, échelle à leur gauche, aucune attribution).

### Choix
`GeoportalFullScreen` en `position: 'bottom-right'` (option geopf) ; échelle OL déplacée en CSS (`MapView.css`), couleurs DSFR ; contrôle
d'attribution supprimé, attributions conservées sur les sources pour l'impression. Détails §12.3.

### Fichiers
`src/hooks/useMapControls.ts` (+ test), `src/config/map.ts`, `src/components/map/MapView.css`, `src/map/labelControls.test.ts`,
`scripts/check-map.ts`, `doc/screenshots/M13/`.

### Tests
Vitest (contrôles créés, position du plein écran, plus d'attribution) ; `check:map` : disposition bas droite à 375/768/1280, couleurs de
l'échelle dans les deux thèmes, plus de `.ol-attribution`.
