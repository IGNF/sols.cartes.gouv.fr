# E1 : socle Eleventy 3 + DSFR (brique edito)

## Objectif
Monter `apps/accueil` (`@sols/accueil`) : Eleventy 3, DSFR 1.14.2, gabarit de base accessible,
en-tête et pied de page partagés, scripts `dev` / `build` / `lint` / `test` utilisables par les scripts racine.

## Fichiers
- `apps/accueil/package.json` : dépendances (`@11ty/eleventy` ^3.1, `@gouvfr/dsfr` 1.14.2 exact, `html-validate`) et scripts.
- `apps/accueil/eleventy.config.js` : entrée `src`, sortie `dist`, copie des seuls fichiers DSFR utiles vers `/dsfr/`
  (CSS, fichiers référencés par ce CSS, favicons, JS module et nomodule).
- `apps/accueil/src/_data/site.js` : URL du site, chemins des sections, liens externes, contenu en-tête / pied de page.
- `apps/accueil/src/_includes/layouts/base.njk` : `lang="fr"`, titre, meta description, canonical, liens d'évitement, `main`.
- `apps/accueil/src/_includes/partials/{skiplinks,header,footer}.njk`.
- `apps/accueil/src/index.njk` : accueil minimal (un `h1`, rempli en E2).
- `apps/accueil/.htmlvalidate.json`, `apps/accueil/test/smoke.test.js`.
- `doc/agents/edito.md` : commandes, structure, balisage rendu de l'en-tête / pied de page pour les autres briques.

## Étapes
1. Dépendances et scripts (`dev` port 8081, `build`, `lint` = build + html-validate, `test` = bun test).
2. Configuration Eleventy et copie DSFR minimale.
3. Données du site, gabarit, partiels, page d'accueil.
4. Lint html-validate, test de fumée, documentation.

## Tests
- `bun run lint`, `bun run test`, `bun run build` dans `apps/accueil`.
- Racine : `bun run build:all` puis `bun run preview:all` ; curl de `/` et des assets `/dsfr/`, capture Playwright 1280 px.
- Test de fumée : `dist/index.html` contient le `h1`, les trois liens de navigation et le lien d'évitement.
