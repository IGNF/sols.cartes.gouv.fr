# E12 : logos partenaires du pied de page sans bordure (brique edito, repris par le catalogue)

## Objectif

Demande du propriétaire : retirer la bordure des logos du pied de page sur l'accueil et le catalogue, comme la grille
de logos de l'accueil et le pied de page carto (M23, PR #112).

## Analyse

Le DSFR 1.14.2 dessine la bordure sur l'image : `.fr-footer__partners .fr-footer__logo { box-shadow: inset 0 0 0 1px
var(--border-default-grey) }`. Le lien `.fr-footer__partners-link` n'a qu'un fond blanc, sans bordure. La plaque
blanche du thème sombre (`background-color: #fff`) est un fond, pas la bordure : elle reste pour le contraste des
logos.

## Fichiers

- `apps/accueil/src/css/site.css` : `box-shadow: none` sur `.fr-footer__partners .fr-footer__logo.sols-partner-logo`.
  Le catalogue n'a pas de copie : `scripts/layout.mjs` (`SHARED_CSS_PREFIXES`, `.sols-partner-logo`) extrait cette
  règle à la préparation.
