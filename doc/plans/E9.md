# E9 : Échap dans les sous-menus du menu mobile (brique edito)

## Objectif

Défaut D-edito-2 (passe e2e T3) : à 375 px, Échap dans le sous-menu « Aide » ou « Services » du menu burger ferme
toute la modale DSFR. Aligner sur la carto (`doc/agents/geopf-ext.md`) : un premier Échap ferme le sous-menu ouvert et
rend le focus à son bouton, un second ferme la modale. Comportement bureau inchangé.

## Analyse

DSFR 1.14.2 : `Navigation._keydown` ne traite Échap qu'au point de rupture LG (`hasOpenedMenu`) ; `Modal._escape`
ferme la modale pour tout élément actif hors champ de formulaire. Aucun attribut ni option DSFR ne change cet ordre :
un petit gestionnaire est nécessaire.

## Fichiers

- `apps/accueil/src/js/header.js` : écouteur `keydown` en phase de capture sur `document` (avant l'écouteur racine
  DSFR posé sur `<html>`) ; si un sous-menu de `.fr-header__menu-links` est ouvert et contient le focus, le referme
  par son bouton (bascule DSFR), rend le focus au bouton et arrête la propagation.
- `layouts/base.njk`, `partage.njk` : chargement du script ; `doc/agents/edito.md` : raison et consigne pour les
  autres briques.

## Tests

Playwright à 375 px (burger, Entrée sur « Services », Échap, Échap ; idem « Aide » et langue) et à 1280 px (inchangé) ;
test unitaire de présence du script ; `bun run lint`, `test`, `build`, `check-links` ; capture.
