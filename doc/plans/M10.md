# M10: chevron des menus d'en-tête (défaut D-carto-3)

Source : troisième passe e2e. Sur la carto, le chevron des boutons « Aide » / « Services » ne se retourne pas quand
le menu est ouvert, alors que celui de l'edito tourne vers le haut (`.sols-tool-menu__btn[aria-expanded='true']::after`,
`rotate(-180deg)`, `apps/accueil/src/css/site.css`).

## Changement

- `HeaderMenu.tsx` : classe `header-menu__btn` sur le bouton ; le chevron reste l'icône DSFR `fr-icon-arrow-down-s-line`.
- `SiteHeader.css` : `.header-menu__btn[aria-expanded='true'] .header-menu__chevron { transform: rotate(-180deg) }`,
  transition 0,3 s comme l'edito, coupée par `prefers-reduced-motion`.
- Tests : `HeaderMenu.test.tsx` (balisage : bouton, chevron DSFR décoratif, `aria-expanded`) ; `check:map` mesure la
  transformation calculée, menu ouvert et fermé (jsdom ne charge pas les CSS).

## Vérification

Lint, typecheck, tests, build, `build:all`, `check:map` ; captures avant/après dans `doc/screenshots/M10/`.
