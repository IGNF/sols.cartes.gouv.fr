# E5 : internationalisation fr / en (brique edito)

## Objectif

Pages sous `/fr/` (langue par défaut) et `/en/` avec `EleventyI18nPlugin` ; chaque chemin sans langue (`/`,
`/mentions-legales/`, ...) devient une page de renvoi (meta refresh vers `/fr/...`, liens visibles vers les deux
versions, sans JS) ; `hreflang` sur chaque page, sélecteur de langue DSFR (`fr-translate`) dans l'en-tête, sitemap
bilingue.

## Fichiers

- `eleventy.config.js` : plugin i18n (`defaultLanguage: 'fr'`), collections `fr` et `articles`, filtre `byLang`,
  linter `seo-head` adapté aux pages de renvoi.
- `src/_data/i18n/{fr,en}.js` : toutes les chaînes d'interface et de contenu par langue (anglais provisoire).
- `src/_data/site.js`, `src/_data/accueil.js` : structure et URL seulement (sans libellés).
- `lib/locale-data.js`, `src/{fr,en}/{fr,en}.11tydata.js` : langue et titre / description tirés de `i18n`.
- `src/{fr,en}/` : accueil, quatre pages du pied de page, liste et articles (gabarits vides + Markdown).
- `src/_includes/layouts/{accueil,articles,reroute}.njk`, partiels avec `locale_url`, `locale_links`, sélecteur.
- `src/reroute.njk` : une page de renvoi par page française (pagination sur `collections.fr`).
- `src/partage.njk` : `/partage/en-tete-pied-de-page/` (noindex), en-tête et pied de page partagés avec chemins
  sans langue, source byte à byte des blocs de `doc/agents/edito.md`.
- `src/sitemap.njk` : deux langues, `xhtml:link` alternates.

## Tests

- Les deux langues : `lang`, h1, canonique, description, `hreflang` fr / en / x-default ; renvois (`/`, pied de page) ;
  sélecteur ; sitemap ; liens internes ; synchro doc. `bun run lint`, `test`, `build` ; `build:all` + `preview:all`.
